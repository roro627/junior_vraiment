# 12 — Contenu, terminologie et microcopy

## 1. Ton

Le produit doit être :

- direct ;
- factuel ;
- compréhensible ;
- prudent ;
- transparent ;
- jamais moralisateur.

Il peut poser une question forte, mais la réponse doit respecter les limites du dataset.

---

## 2. Nom et signature

### Nom

```text
Junior, vraiment ?
```

Conserver la virgule et le point d'interrogation dans le nom éditorial. Pour les slugs, packages et variables :

```text
junior-vraiment
```

### Signature principale

```text
Le marché tech junior, mesuré plutôt que raconté.
```

### Alternative courte

```text
Ce que demandent vraiment les offres tech junior.
```

### Description

```text
Un observatoire indépendant qui analyse des offres d'emploi tech actualisées pour mesurer l'expérience réellement demandée, la transparence salariale et les tendances du marché junior.
```

---

## 3. Formulation du KPI

### Recommandée

```text
38 % des offres se présentant comme « junior » demandent au moins 2 ans d'expérience.
```

Sous-texte :

```text
123 offres sur 324, dans ce périmètre et avec une exigence d'expérience classable.
```

### Variante faible échantillon

```text
19 offres sur 43 demandent au moins 2 ans d'expérience.
Échantillon limité : interprétez ce résultat avec prudence.
```

### Aucun échantillon

```text
Pas assez de données pour calculer un pourcentage fiable.
Élargissez le territoire ou retirez une technologie.
```

### Interdite

```text
38 % des entreprises mentent.
```

Raison : le produit observe une formulation, pas l'intention.

## 6. Tooltips et aide

### Junior contradictoire

```text
L'offre se présente explicitement comme junior et demande au moins 24 mois d'expérience obligatoire selon les preuves détectées.
```

### Offre classable

```text
Une offre est classable lorsque les informations disponibles permettent de déterminer de façon suffisamment fiable si le seuil d'expérience est atteint.
```

### Salaire transparent

```text
L'annonce fournit une rémunération chiffrée exploitable. « Selon profil » seul n'est pas considéré comme un salaire affiché.
```

### Technologie citée

```text
La technologie apparaît dans l'annonce. Sa présence ne signifie pas nécessairement qu'elle est obligatoire.
```

## 7. Fraîcheur

### Fresh

```text
Données mises à jour aujourd'hui
```

### Delayed

```text
Mise à jour retardée
La dernière collecte complète date du {date}.
```

### Stale

```text
Données anciennes
Ces chiffres n'ont pas été actualisés depuis {duration}. Consultez l'état des données avant de les partager.
```

### Partial

```text
Données partielles
Certaines requêtes n'ont pas abouti. Les résultats disponibles peuvent ne pas couvrir tout le périmètre habituel.
```

## 8. Erreurs

### Générique

```text
Cette partie n'a pas pu être chargée.
Les autres données restent disponibles. Réessayez.
```

### Filtres

```text
Ce filtre n'est plus disponible.
Nous l'avons retiré de la sélection.
```

### Explorer

```text
Impossible de charger les offres correspondantes.
Le chiffre précédent reste affiché, mais sa liste de preuve est momentanément indisponible.
```

### Source externe

```text
L'offre source n'est peut-être plus disponible.
Elle a été observée pour la dernière fois le {date}.
```

Ne pas écrire « Oups ! » partout. L'erreur doit être calme et utile.

---

## 9. Chargement

Éviter les textes trop bavards.

```text
Mise à jour des résultats…
Chargement des offres…
Préparation de la preuve…
```

Ne pas afficher « Analyse de milliers d'offres par notre intelligence artificielle » : ce n'est pas le fonctionnement prévu.

---

## 10. Méthodologie courte

Bloc près du KPI :

```text
Comment ce chiffre est-il calculé ?

Nous repérons les offres qui se présentent explicitement comme junior, puis les exigences d'expérience obligatoires. Une offre est dite contradictoire lorsqu'elle demande au moins deux ans. Les cas ambigus sont séparés, et chaque classement conserve ses preuves.
```

Action :

```text
Lire la méthode complète
```

## 12. À propos

Proposition :

```text
Pourquoi ce projet ?

Les discussions sur l'emploi junior sont remplies d'expériences individuelles difficiles à comparer. Junior, vraiment ? transforme des offres actualisées en indicateurs ouverts et vérifiables.

Le projet n'est ni un site de candidature, ni un classement d'entreprises. Il cherche à rendre le marché plus lisible.
```

---

## 13. Corrections

```text
Une offre vous semble mal classée ?

Consultez d'abord les preuves et la version de méthode, puis signalez le cas. Toute correction durable devient un test et une règle versionnée.
```

Après correction :

```text
Ce résultat a été corrigé le {date}.
La version précédente utilisait {oldValue}. Consultez le détail du changement.
```

## 14. Partage

### Modal

Titre :

```text
Partager ce constat
```

Aide :

```text
La carte inclut le périmètre, la période et l'échantillon afin de garder le chiffre compréhensible hors du site.
```

Confirmation :

```text
Lien copié
```

Échec :

```text
Le lien n'a pas pu être copié. Sélectionnez-le manuellement.
```

## 17. Règles de nombres

- afficher fraction et pourcentage ;
- maximum une décimale ;
- arrondir seulement à l'affichage ;
- utiliser `points` pour différence de taux ;
- afficher `≈` si valeur réellement approximative ;
- ne pas ajouter de précision factice ;
- annoncer faible échantillon ;
- ne pas cacher inconnus/ambigus.

---

## 18. Règles de capitalisation

Interface française en casse phrase :

```text
Expérience demandée
```

Pas :

```text
Expérience Demandée
```

Technologies avec leur graphie officielle :

```text
React Native
Next.js
TypeScript
Node.js
PostgreSQL
```

---

## 19. Inclusivité

Utiliser une formulation neutre lorsque naturelle :

```text
personnes débutantes
profils juniors
candidatures
jeunes diplômés et diplômées
```

Ne pas alourdir chaque phrase. La clarté reste prioritaire.

## 20. Revue de contenu

Avant publication, vérifier :

- sujet ;
- population ;
- date ;
- source ;
- fraction ;
- définition ;
- inconnus ;
- ambiguïtés ;
- comparaison ;
- absence d'accusation ;
