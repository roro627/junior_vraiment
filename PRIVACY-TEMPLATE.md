Le site ne requiert pas de compte et ne collecte pas de CV.

Des données techniques minimales peuvent être traitées pour :

- fonctionnement ;
- sécurité ;
- mesure d'audience ;
- diagnostic d'erreur.

Décrire précisément les fournisseurs activés, les événements, les durées et les bases juridiques.
